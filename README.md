# 🎟️ Eventify — AI-Powered Event Booking Platform

Eventify is a modern and responsive **event discovery and booking web application** built with React.js and Antigravity. It allows users to discover events, explore event details, select tickets, and manage their bookings through an intuitive user interface.

The project also demonstrates how **Artificial Intelligence can be integrated into a real-world web application** to improve the user experience through personalized event discovery and recommendations.

---

## ✨ Features

### 🎟️ Event Booking

* Browse available events
* View detailed event information
* Select ticket types and quantities
* Review booking details
* Complete the booking flow
* View booking confirmation

### 🔎 Event Discovery

* Search for events
* Browse events by category
* Explore different event types
* View event details and pricing
* Responsive event cards

### 🤖 AI Integration

Eventify is designed to demonstrate practical **AI integration in a frontend application**.

AI can be used to:

* 🤖 Recommend events based on user interests
* 🎯 Personalize event discovery
* 🔍 Understand natural-language event searches
* 💡 Suggest similar events
* 📊 Improve recommendations based on user interactions
* 💬 Provide an AI-powered event discovery assistant

The goal is to demonstrate not only frontend development skills but also an understanding of **where and how AI can add value to a real-world application**.

---

## 🧠 AI Application Concept

The AI functionality can be integrated into the event discovery experience.

For example, instead of searching only with keywords, a user could enter:

"Find me a technology event in Pune this weekend."


The AI system can understand the user's intent and help identify relevant events.

Another example:
"I like music and outdoor events. What should I attend?"

The application can use AI-based recommendations to suggest suitable events.

This demonstrates a practical use case of AI rather than using AI only as a separate chatbot.
